Безопасно

Критичные команды защищены, токен хранится в локальном файле .env.

🚀 Как установить

1

Скачай файлы бота — main.py, setup.py и start_bot.bat из репозитория.

2

Установи Python 3.11+ и зависимости: pip install -U fluxer aiosqlite python-dotenv

3

Создай файл .env рядом с ботом и впиши туда токен: BOT_TOKEN=твой_токен

4

Запусти start_bot.bat — откроется панель управления. Нажми «Запустить» и пиши !help в чате!
